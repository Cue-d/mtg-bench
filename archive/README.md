# Historical research

These are preserved research and run snapshots from the earlier gym prototype,
not instructions for the current player-scoped bridge. Paths in their prose
refer to the repository layout at the time. The full old runtime is recoverable
from Git commit `4ea6e4c`.

- `00_admin/`: research status and source ledger.
- `01_landscape/`: engines, data sources, and game-agent precedents.
- `02_prototypes/`: original result artifacts and standalone source probe.
- `03_architecture/`, `04_datasets/`, `06_decisions/`: historical proposals and decisions.
- `DEPENDENCIES.md`: historical dependency and verification notes.

Use [the root README](../README.md) for current setup and tests.
